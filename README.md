## ★ 相比 V2.0.5 更新了什么

V2.0.5 的基线是 device `v1.3.329` + player `pl-1.6.148`；
V2.0.6 的基线是 device `v1.3.360` + player `pl-1.6.163`。

这一版的主线是**播放记录与进度**：把「谁在放、放到哪、换台设备还能不能接上」这条链做实。
在此之上补了语音读时长/跳转、合集子书点名播、续播的本地/缓存/在线三级查找，
以及「只说书名就接着上次听」的起播点修正（不再落第 0 集预告）。

### 一、播放记录 / 进度上报（本版主线）

| # | 能力 | 说明 |
|---|---|---|
| 1 | 暂停立即结算 | 网页暂停/停止、实体键暂停、语音 stop、设备关机**四条路**都立刻结算上报，不再等下一拍（v1.3.340 / pl-1.6.156） |
| 2 | 位置同步带设备身份 | `/v1/pos` 上报、拉流 URL 都带 `dev=`（MAC12）；群晖 docker 下 R1 的记录不再误落「网页」桶（v1.3.342/346） |
| 3 | 起播即上报 | `ProgProgress` 每 2 秒**轻探** player 指纹（曲名\|curId\|playing\|pos>3s），指纹变化或 15 秒到期才真正 tick；不再为一次判断拉整张队列（v1.3.349） |
| 4 | 位置门槛放开 | 起播瞬间 pos 就是 0，原「pos<8 秒不报」会把起播那一拍挡掉；服务端对**带 devId** 的低位置上报放行（v1.3.349） |
| 5 | 入队盖章 | 谁把书排进队列谁写队列项 `album`（书名），device 只读不算 —— 不再靠猜「这是哪本书」（v1.3.350） |
| 6 | 书级共享进度 | 续播先问服务端 `/v1/resume?q=&dev=`（含「听完⇒下一集」），命中就把集号/秒数写回本地；换台设备也能接着听（v1.3.336/347） |
| 7 | 电台判据改 URL 形态 | 电台的 `liveStream`/`qRadio` 在起播瞬间**都是 false**，靠它判会把广播漏报；改成按 URL 形态（`/radio/`、外网直链）判定（v1.3.352） |
| 8 | 上报名统一短名 | 记录里书名与队列/列表显示用同一套短名，避免同一本书两个名字（v1.3.351） |

### 二、听书身份唯一化（v1.3.348）

| # | 变化 |
|---|---|
| 1 | **合集子书的书身份 = 子书名**（「黑暗森林Ⅱ」「死神永生Ⅲ」），合集名（「三体」）只作 `series` 展示位 |
| 2 | 记录里**不带父名前缀** —— 否则三部曲会被记成同一本、进度互相覆盖 |
| 3 | 禁止用全局「上一本书」兜底：认不出书名就**不上报**，宁缺毋滥（这是「本地书被记成上一本在线书」的根因） |
| 4 | 服务端不再拿 stream 记录反推集号（预载下一首也带 `live=1`，会把第 1 集改成第 2 集） |

### 三、合集（coll）语音点播（v1.3.353~357）

| # | 变化 |
|---|---|
| 1 | `ablFind` 不再一票跳过合集目录，合集本身可播 |
| 2 | **指名播**：说「黑暗森林」就播那一部，不再总是落回合集第一个子书 |
| 3 | 合集子书按子书名找本地文件与续播记忆，与单本同一套逻辑 |

### 四、语音读时长 / 快进后退 / 跳到第几秒（v1.3.358）

| # | 变化 |
|---|---|
| 1 | 新 MCP 工具 `self.r1player.seek_play`（第 37 个工具），语义与 stem 固件 `self.stem.seek_play` 一致 |
| 2 | `sec` = 绝对秒（「跳到第 12 分钟」⇒ 720）；`delta` = 相对秒（「快进 30 秒」⇒ 30，「后退 2 分钟」⇒ -120）；**都不传 = 只查进度** |
| 3 | `status` 末尾追加「已播到 X，共 Y，还剩 Z」；有书名时报「《书名》第 N 集」 |
| 4 | 直播流一律拒绝：判据是 **`durMs<=0`**（电台的 `liveStream` 起播瞬间是 false，不能靠它）；越界钳到 `dur-2` 秒，避免拖到片尾直接跳下一集 |
| 5 | 网页同入口：`/api/act?op=progress`、`op=seek_play&sec=NNN`、`&delta=-60` |

### 五、续播查找顺序：本地库 → 缓存 → 在线（v1.3.359）

| # | 变化 |
|---|---|
| 1 | 本地库同名书可能只是**残卷**（实测 `/audiobook` 里《凡人修仙传》只剩 3 集，在线版 2113 集），而 `ab_loader_album` 会一直指着它 |
| 2 | 本地集表里找不到目标集时，自动退 `/api/ab/episodes?q=&ep=`（服务端内部是 `ab_cache.json` 永久缓存优先、未命中才回源 = 缓存+在线两级） |
| 3 | 再找不到（换了短版本）⇒ 退到 ≤目标集的最近一集，话术改成「这版没有第 N 集（共 M 集）—— 从第 K 集继续」，不再回「找不到可播的那一集」（小智会把它转述成「找不到上次播放的记录」） |
| 4 | 降级成功后把 loader 纠正成在线 albumId，下次不再踩同一个坑 |

### 六、续播起播点修正：只说书名就接着上次听（v1.3.360）

| # | 变化 |
|---|---|
| 1 | **`ab_play` 不带集号 = 接上次听**：依次问服务端书级 `/v1/resume` → 我的节目 Prog → SP 最近听书记忆，拿到集号/秒数就按它起播，起播后自动定位到那个位置（统一回退 10 秒）；从没听过的书才落第 1 集。想从头听要说「从第 1 集播」（带 `ep=1`，不走这条） |
| 2 | 修掉「只说书名播成**第 0 集 预告**」：原来无集号分支直接取本地集表**第一行**，绕过 `abPick` 已有的「跳过 `ep<=0`」保护，而本地书的第 0 集往往正是预告 |
| 3 | 本地集表**一律走 `abPick`**：无集号时跳过 `ep<=0`；指定集号而本地取不到时**保持空、让位在线**（本地 3 集残卷续播第 14 集靠这条，兜底成第一行就会又播预告） |
| 4 | `abQueueBook` 过滤 `ep<=0` 的预告/片花/花絮/宣传/片头曲/片尾曲/主题曲/彩蛋，不再坐队首当起播集（「引子/序」的 `ep` 通常是 1，不受影响） |
| 5 | 一并修掉「服务端没有记录」：播到第 0 集时 `ProgProgress` 会整条丢弃（`ep<=0`），所以既播错又无记录 —— 起播点对了，上报自然恢复 |

### 七、缺集救援 / 脏缓存（v1.3.332~335）

| # | 变化 |
|---|---|
| 1 | 按需单点（带 `ep=N`）时把集号透传给服务端，缺集占位播到才有机会被救援回来 |
| 2 | 历史「错误缓存」里的脏占位行（带假 rid）强制重问服务端一次 |

| 4 | 歌曲解析服务端优先（吃 `/api/song/resolve` 的 rid 缓存），减少一次上游搜索 |

### 八、网页控制台 / player（pl-1.6.149~163）

### 九、「退下」本地兜底（v1.3.330）

云端不一定把「退下」映射到 MCP 工具；本地对高置信度短语直接退出 LISTENING，保证真的闭嘴。

### 十、已知遗留（不影响日常使用）

| 项 | 说明 |
|---|---|
| 播放列表不持久 | 设备重启 / 重装任何一个包，播放进程一起重启 ⇒ 播放列表清空，重新点一次「导入播放列表并播放」即可 |
| 红标是内存态 | 「没配上」是 player 的会话内判定，player 重启后全部消失。**重启后不红了 ≠ 修好了** |
| 自动匹配仍可能配到翻唱 | NAS 搜索按热度排序，用**长按歌名 → 重链接**兜底 |
| 本地库残卷 | 同名书本地只剩几集时会先按本地播（本地优先），集号超范围才降级到在线；想直接听完整版可说在线版主播名或先清掉本地目录 |
| 书名号套娃 | 本地书的 name 自带书名号时，语音回话会出现「《《庆余年》有声小说》」（能播，只是文案难看） |
| 随机闹钟只吃在线池 | 断网时随机响铃可能放不出声（指定铃声有缓存，不受影响） |
| 长按 / 三击未接管 | 仍是原厂的 WiFi 配网 / 蓝牙配对 |

## 构建

```bash
cd 04-build-scripts/device   && bash build_rel_V206.sh    # → XiaoZhi_Unisound_V2.0.6.apk
cd 04-build-scripts/player   && bash build_rel_V206.sh    # → XiaoZhi_EchoService_V2.0.6.apk
```

发布脚本是**生成**出来的（`_gen_rel_v206.py` 读日常脚本改名、并在 javac 前临时把版本串
改成 `2.0.6` / `pl-2.0.6`，构建完立刻还原）；源码树永远停在测试序列
（`XzBootstrap.VERSION = 1.3.360`、`Boot.VER = pl-1.6.163`），两条线不会串。
工具链放 `04-build-scripts/tools/`（或 `R1_TOOLS=<目录>`），详见 `04-build-scripts/环境说明.md`。

## 安装 / 升级

> 完整图文步骤（装 APK、落雪、MyXiaoZhi_MediaServer、各端配置、语音工具全表、排错）见
> **[安装使用说明_通用版.md](安装使用说明_通用版.md)**；服务端单独维护在
> https://github.com/shj4588/MyXiaoZhi_MediaServer 。

1. 音箱固件必须是 **3448**，与电脑同一网络、已开 adb 网络调试。
2. 装两个包（覆盖安装，收藏、闹钟、「我的节目」与设置都保留）：
   `XiaoZhi_Unisound_V2.0.6.apk` → `com.phicomm.speaker.device`；
   `XiaoZhi_EchoService_V2.0.6.apk` → `com.phicomm.speaker.player`；
   首次装还需 `XiaoZhi_SoHost_V2.0.1.apk`（Opus so 只能由系统安装器解出）。
3. 浏览器打开 `http://<音箱IP>:8080/` → 顶部「激活」卡片取 6 位激活码 → 到小智服务端绑定。

**升级提示**

- 装完 device 包，播放列表会清空（见「已知遗留」），收藏、闹钟、「我的节目」不受影响。
- 从 V2.0.4 及更早升级，浏览器可能还压着旧页面（旧版给了 10 分钟强缓存）：
  等顶部「页面已过时」横幅出现点一下，或手动刷新一次。
- 本地有声书库要服务端 ≥ v1.2.1（`/api/abl/*`）；V2.0.6 的续播降级、书级共享进度建议配
  MyXiaoZhi_MediaServer ≥ V1.7.55。

## 语音控制：MCP 工具全表（37 个）

R1 作为 MCP 端点注册到小智服务端，工具分四组前缀：`self.r1player.*`（播放，28 个）、
`self.r1light.*`（灯，2 个）、`self.r1alarm.*`（闹钟，6 个）、`self.r1session.*`（会话，1 个）。

两条使用前提：

- 服务端**只在连接握手时拉一次**工具表。改过设置里的「自定义音乐库」开关后，要重新唤醒
  （说一句「小智小智」）或点控制台「重启小智」，新表才生效。
- 关掉「自定义音乐库」开关 ⇒ 只下发 9 个（灯 2 + 闹钟 6 + 退下 1），音乐工具全部消失。

### 1. 播放 `self.r1player.*`（28 个）

| 工具 | 语音示例 | 参数 / 说明 |
|---|---|---|
| `play_song` | 「播放晴天」「我想听周杰伦的晴天」 | `title`：歌手+歌名一起给更准；本地没有就自动在线搜 |
| `play_artist` | 「放周杰伦的歌」「来三首邓丽君」 | `artist`、`count`（不传 = 一直连播） |
| `play_index` | 「放第 8 首」 | `index`：**曲库**里的第 N 首（从 1 开始） |
| `play_at` | 「跳到列表第 3 首」 | `index`：**当前播放列表**里的第 N 首 |
| `search` | 「库里有没有邓丽君」「有哪些歌手」 | `keyword`：只查不播 |
| `list` | 「曲库里都有什么」 | 无参：本地曲库概况（歌手/数量） |
| `random` | 「来点音乐」「随机放 5 首」 | `count`：不传 = 整库随机一直放 |
| `random_online` | 「随机播放在线音乐」「换一批」 | `count`：默认 100，每次换一批新的 |
| `pause` / `play` / `stop` | 「暂停」「继续」「停止」 | 无参；`play` = 从暂停处续播 |
| `next` / `prev` | 「下一首」「上一首」 | 无参；播有声书时 `next` 也按「下一集」处理 |
| `volume` | 「音量调到 50」「声音大点」 | `level`：0~100 |
| `play_radio` | 「播放先锋898」「第三个电台」 | `name` 或 `index` |
| `play_radio_all` | 「所有电台都放一遍」 | `name` / `index` 可选，不传 = 全部 |
| `play_url` | 「放这个链接 https://…」 | `url`：只播用户明确给出的完整地址 |
| `status` | 「现在放的什么歌」「在放吗」 | 无参：本地记录 + DLNA 状态 + **进度（已播到/共/还剩）** |
| `seek_play` | 「这集还剩多久」「快进 30 秒」「跳到第 12 分钟」 | `sec` 绝对秒 / `delta` 相对秒 / **都不传 = 只查进度**（详见下表） |
| `fav_add` / `fav_del` | 「收藏这首歌」「取消收藏」 | `title`/`artist` 可空 = 对当前在放这首操作 |
| `play_fav` | 「播放我喜欢的歌」 | 无参：播放收藏列表 |
| `ab_search` | 「有没有三体的有声书」 | `keyword`、`narrator`（主播，可选） |
| `ab_play` | 「放三体」「听凡人修仙传」 | `book`、`ep`（集号，**不传 = 接着上次听到的那一集**；从没听过的书才从第 1 集起）、`narrator`；**合集子书可点名**（说「黑暗森林」就播那一部） |
| `ab_next` / `ab_prev` | 「下一集」「上一集」 | 无参：只在有声书语境生效 |
| `ab_resume` | 「继续听上次那本」 | `book` 可空 = 用上次那本；查找顺序 **本地库 → 缓存 → 在线 → 最近集** |
| `prog_addcur` | 「收藏这本书」 | 无参；**toggle** 语义，再调一次即移出「我的节目」 |

**`seek_play` 参数语义**（与 AlphaPi STEM 固件的 `self.stem.seek_play` 一致）

| 调用 | 含义 |
|---|---|
| 不传参数 | 只查：「已播到 7:05，共 14:07，还剩 7:02」 |
| `sec=720` | 跳到绝对 720 秒（第 12 分钟） |
| `delta=30` / `delta=-120` | 快进 30 秒 / 后退 2 分钟 |
| 直播流 | **`durMs<=0` 一律拒绝**并说明原因（电台 `liveStream` 起播瞬间是 false，不能靠它判） |
| 越界 | 钳到片尾前 2 秒，避免拖到结尾直接跳下一集 |

### 2. 灯光 `self.r1light.*`（2 个）

| 工具 | 语音示例 | 参数 |
|---|---|---|
| `ambient` | 「开氛围灯」「调成蓝色」「亮一点」「渐变快点」「关掉氛围灯」 | `on`(on/off)、`mode`(0 官方 / 1 七彩旋转 / 2 七彩 / 3 七彩旋转1 / 4 单色)、`luma`(1~200)、`chroma`(0~100)、`color`(单色模式用) |
| `night` | 「开夜灯」「夜灯只开下面的灯」「夜灯调成暖橙色」「关掉夜灯」 | `on`、`top`(顶部拾音灯)、`amb`(底部氛围灯)、`color`、`luma`(0~100，默认 30)；夜灯期间唤醒/播报灯全部停用 |

### 3. 闹钟 `self.r1alarm.*`（6 个）

| 工具 | 语音示例 | 参数 |
|---|---|---|
| `add` | 「每天早上七点叫我」「周一到周五七点半」「明天七点叫我」 | `hour`、`minute`、`repeat`(once/daily/weekly)、`days`(1~7，可 `1-5`)、`date`(2026-10-27)、`label`；默认随机播一首歌当铃，响铃音量独立、事后自动还原 |
| `list` | 「我有哪些闹钟」 | 无参 |
| `toggle` | 「把七点的闹钟停用」（以后都不响） | `index` 或 `hour`/`minute` 定位；`enabled`(on/off，不传 = 翻转) |
| `dismiss` | 「把七点的闹钟关掉别响了」（**正在响时**） | 只关这一次，明天照响 |
| `del` | 「把七点的闹钟删了」 | `index` 或 `hour`/`minute` |
| `vol` | 「闹钟音量调到 60」 | `v`：20~100，不传 = 只查 |

> 「关闭 / 停用 / 删除」是三件事：响铃中喊「关闭」= `dismiss`（这次别响）、「停用」= `toggle`（以后不响）、
> 「删除」= `del`（彻底没了）。

### 4. 会话 `self.r1session.*`（1 个）

| 工具 | 语音示例 | 行为 |
|---|---|---|
| `quit` | 「退下」「别说了」「安静」「下线」「再见」「不用你了」 | 结束本轮会话：停麦、退出聆听、断连、熄拾音灯，等下次唤醒词。**不要**用 `pause`/`stop` 代替。云端不一定把「退下」映射到工具，本地同时保留了高置信度短语的兜底退出 |

> 同一套入口网页/脚本也能调（便于排查，不用对着音箱喊）：
> `http://<音箱IP>:8080/api/act?op=<工具名>&<参数键>=<值>`，例如
> `/api/act?op=seek_play&sec=300`、`/api/act?op=progress`、`/api/act?op=ab_play&book=三体&ep=2`。
> 中文参数记得 URL 编码。
